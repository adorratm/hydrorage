# HydroRage home screen widget

## Durum
Veri köprüsü: `apps/mobile/lib/widget.ts` (`buildWidgetPayload` / `publishWidgetPayload`).

## iOS
WidgetKit extension + App Group (`group.com.hydrorage.app`). Dashboard yenilenince payload yazılır.

## Android
Glance / `react-native-android-widget` ile kalan ml gösterimi.

## Derin link
Widget dokunuşu → `https://hydrorage.com.tr/app` (universal / app link).
